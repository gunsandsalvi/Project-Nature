# Light tables and palette versions

Index-to-index tables and the palette's versions (A11.3, `PRE-21`, `PRE-30`), each in the approved mockup's own numbers, so every pixel stays a palette colour.
A table maps each colour to the nearest colour it may give (OKLab distance, chroma weighted 1.3) after its change; its rows in the table texture follow the mockup's order: warm 1–3, haze 1–3, outline, sun rim, fire rim, darker, lighter, snow.
A version changes every colour but those it keeps; its rows in the palette texture are dusk, dawn, day and night.
Numbers are written as decimal strings, exactly as the mockup writes them.
